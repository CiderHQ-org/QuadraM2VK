# The SPIR-V grammar items the translator names: generate.py emits these into
# crates/metal2vulkan/src/spv.rs and nothing else. A value the code names that is missing here
# fails to build; a value listed here that nothing uses is dead code, which rustc reports where it
# can see it (not for a type the crate's public impls reach, such as `Op` through `BuildError`).
# Values only test code names go in test-values, so the library build has none of them.
#
#   type Word | const MAGIC_NUMBER   the word type; the module header's first word
#   enum <Kind> [test]               an operand kind of the core grammar by its grammar name (a
#                                    mask for a BitEnum kind), `Op` for the core instructions or
#                                    `GlslStd450Op` for GLSL.std.450's; `test`: in test builds only
#   from_u32 [test]                  the kind's word-to-value conversion (it needs every value)
#   values <Name>... | *             values every build has, by their Rust names (generate.py's
#                                    variant_name and const_name); `*`: all not named yet
#   test-values <Name>... | *        values only test builds have
